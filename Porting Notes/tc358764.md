# Toshiba TC358764 DSI→LVDS bridge

* Device reference: I²C0x0f on SDA2/SCL3, ID 0x6500. Register addresses are
  big-endian and returned data little-endian. Input is four-lane DSI; output
  feeds the1280×800LVDS panel. Successful command DMA alone did not prove
  bridge registers changed or real scanout reached the panel.
* Recorded working registers: PPI_LPTXTIMECNT4, TX_RX_TA 0x50006, all CLRSIPO4,
  PPI/DSI lane enables0x1f, VP_CTRL 0x03f00120, HTIM1/2=0x00300002/0x00300320,
  VTIM1/2=0x00400002/0x00200500, LV_CFG1, LV_PHY0=0x48006. Interpret stored
  bridge timing words through the vendor transport, not as bare DRM dimensions.
* Patches 0047–0049 validate transfer lengths and the matisse profile;0071
  handles first initialization/write order. The host uses LP11 reset,
  deferred-video and PHY profile7 while sending initialization commands.
* 0135 controls LCD enable using PM8226GPIO2 in vendor reset/enable order.
  Separate bridge supplies remain unidentified and L5/firmware retention stays;
  do not assign arbitrary regulator pins or call backlight-off full power-off.
