# Cortex-A7 CPU complex: hardware IP

* **SOURCE (r02/SoC):** MSM8226 v2 contains four `arm,cortex-a7` CPU0–3 in one SMP cluster, shared unified L2, Cortex-A7 PMU, and GICv2; CPU identification, working OPPs and bounded tests are in [cpu](cpu.md). This is *CPU IP*, not the complete Qualcomm SoC.
* **ARM Cortex-A7 architecture (not r02-specific physical measurements):** per-core instruction-fetch/prefetch/branch prediction and instruction cache; execution unit with ARMv7-A/Thumb-2, NEON/VFPv4; data cache/store buffer/bus interface; CP15/MMU, instruction/data micro-TLBs and main TLB. The cluster has an SCU for cache coherency and an ACE-facing memory interface. Do not infer this board's cache **capacities** or exact MIDR revision from a generic Arm reference.
* **SOURCE (mainline):** CPU0–3 use `qcom,msm8226-smp`, share an `opp-shared` CPU table and `next-level-cache = <&l2>`; PMU is `arm,cortex-a7-pmu` (per-CPU GIC PPI7). ETM0–3 CoreSight sources occupy `0xfc33c000`/`0xfc33d000`/`0xfc33e000`/`0xfc33f000`.
* **Clock path:** APCS/KPSS syscon/mailbox `0xf9011000`; A7 PLL `0xf9016000`. CPU frequency switching, APC voltage, CPU-memory rail and RPM-CX votes are separate decisions. Mainline PLL OPP entries above 1190.4 MHz are *capabilities/table entries*, not verified r02 operating frequencies.
* **Power hardware:** SAW2/SPM per CPU0–3 at `0xf9089000`/`0xf9099000`/`0xf90a9000`/`0xf90b9000`; separate L2/APCS SAW at `0xf9012000`. WFI, standalone collapse, L2 retention/GDHS, RPM-coordinated states and CPU-hotplug have distinct requirements; only the bounded paths in [power management](power-management.md) are accepted.
* **DEVICE:** seven active OPPs through 1190.4 MHz, measured PMU cycles/core and L2 clock are already recorded in [cpu](cpu.md). Neither timing-only cache benchmarks nor a successful PMU cycle count establish cache size, cache miss counters, bin/fuse value, measured voltage, or all instruction-set extensions enabled at runtime.
* **Unresolved inventory:** per-core MIDR/REVIDR and feature-register readback, L1I/L1D/L2 size/ways/line geometry from CLIDR/CCSIDR or sysfs, event-counter coverage, actual speed-bin/PVS, thermal/voltage margins and cache power retention. Gather read-only observations; do not decode/dump secure fuses or infer vendor-selected bins from the maximal generic table.
